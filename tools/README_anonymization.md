# Локальное обезличивание выгрузок приемной кампании

Скрипт `anonymize_admissions_data.py` нужен для подготовки демо-данных без персональных данных. Он запускается только локально, читает файл с диска и сохраняет обезличенную копию рядом или в указанную папку. Сетевых запросов, API и отправки данных наружу в нем нет.

## Как запускать

### Оконное приложение

Самый удобный вариант:

```powershell
.\tools\open_anonymizer_app.bat
```

Откроется окно, где можно:

- выбрать исходный CSV/XLSX-файл из любой закрытой папки вне проекта;
- выбрать лист XLSX;
- увидеть, как будут обработаны колонки;
- выбрать папку результата;
- нажать «Обезличить».

Реальная выгрузка не должна лежать в папке проекта. Ее можно выбрать из закрытой локальной папки, например `D:\закрытые_данные\...`.

### Командная строка

Самый простой вариант в PowerShell:

```powershell
.\tools\run_anonymizer.ps1 -InputFile "data\raw\source.xlsx"
```

С явным выходным файлом:

```powershell
.\tools\run_anonymizer.ps1 -InputFile "data\raw\source.xlsx" -OutputFile "data\anonymized\source_anonymized.xlsx"
```

Прямой запуск Python-скрипта:

```powershell
python tools/anonymize_admissions_data.py "data/raw/source.xlsx" -o "data/anonymized/source_anonymized.xlsx"
```

Для CSV:

```powershell
python tools/anonymize_admissions_data.py "data/raw/source.csv" -o "data/anonymized/source_anonymized.csv"
```

Если нужен стабильный, но другой набор псевдонимов:

```powershell
$env:ANONYMIZER_SALT="local-secret-2026"
python tools/anonymize_admissions_data.py "data/raw/source.xlsx" -o "data/anonymized/source_anonymized.xlsx"
```

## Что делает скрипт

- Добавляет `anon_applicant_id`.
- Заменяет ФИО на стабильные псевдонимы `Абитуриент 0001`, `Абитуриент 0002` и т. д. Если один человек встречается в нескольких строках, он получает одно и то же имя и один `anon_applicant_id`.
- Заменяет телефоны и email на технические псевдозначения.
- Заменяет паспорта, СНИЛС, ИНН и документы на `[удалено]`.
- Оставляет от даты рождения только год.
- Обезличивает адреса и свободные комментарии.
- Сдвигает даты событий на несколько дней, чтобы сохранить динамику без точных дат.
- Сохраняет учебные и аналитические поля: направление, программа, баллы, приоритет, статус, этап воронки, источник, согласие, договор, оплата и т. п.
- Создает JSON-отчет с перечнем колонок и примененных правил, без исходных значений.

## Безопасная организация папок

Рекомендуемая структура:

```text
data/
  raw/          # реальные выгрузки с ПДн, не публиковать
  anonymized/   # обезличенные копии для демо и разработки
```

В `.gitignore` добавлены правила, чтобы `data/raw/`, `data/private/` и `data/anonymized/` не попадали в репозиторий случайно.

## Важно

Перед публикацией на GitHub проверяйте, что в демо-файлах не осталось колонок с прямыми идентификаторами: ФИО, телефон, email, паспорт, СНИЛС, ИНН, адрес, свободные комментарии.
